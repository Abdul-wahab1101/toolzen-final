TEST HARNESS CAVEATS
--------------------
- Some isolated tests stubbed browser/CDN-provided dependencies (formatter and cryptographic API) to verify the application call path and output rendering. Those stubs are not the production libraries.
- The environment could not resolve some external CDN hosts, so these features were NOT fully end-to-end verified against their live dependencies here: QR library generation/scanning, js-beautify formatters, QPDF WASM password operations, PDF.js/pdf-lib file transformations, Tesseract OCR, SheetJS/html2pdf spreadsheet conversion and TTS voice availability.
- File-specific tests do not cover every malformed file, maximum-size file, browser/device, language, or memory condition.
- “91/91 workspaces initialized” confirms the UI route/control initialization only; it is not a claim that every third-party library operation and every export format has been exhaustively tested.

KNOWN PRODUCT LIMITS
--------------------
- Password strength is a local heuristic, not a breached-password database check.
- BMI is an adult screening guide, not a diagnosis.
- Tax, GST, salary and electricity calculators use user-provided rates; official rates do not auto-update.
- JWT Decoder does not verify a token signature.
- PDF text extraction/word count requires selectable text; scanned PDF pages need OCR.
- JPG to Word uses English OCR and outputs Word-compatible HTML/.doc, not a layout-preserving DOCX.
- PDF metadata cleanup targets common document information fields and cannot guarantee all XMP/custom metadata is erased.
- QPDF/WASM, OCR, QR, spreadsheet and formatter functions need internet access to load public CDN libraries when first used.
- Camera QR scanning requires HTTPS, browser support and camera permission.
- Notepad autosave depends on browser localStorage; TXT download remains available if storage is blocked.
