Frequently asked questions

Can I set a target file size?

Yes. The compressor includes a target-size setting. A very small target may require lower image quality, and exact results depend on the original image.

Are my images uploaded?

Image compression is performed in your browser. ToolZen does not need your image file to be uploaded to its server for this tool.

Which formats can I use?

Common supported formats include JPG, PNG and WebP. The available output options depend on the selected settings and browser support.
